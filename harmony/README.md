# 刻时 HarmonyOS 1.0

当前版本 1.0.1，以 Android 1.0.37 为功能基线，在 ArkWeb 中复用原有移动端界面、业务数据格式与日程算法。不是 APK 改名，也不依赖电脑服务运行。此版同步时间滚轮中央吸附/循环选择，以及待收纳拖入时间轴、调整结束时间和双击无尾；详见项目根目录 `时间滚轮与待收纳拖动验收.md`。

最低系统：HarmonyOS 5.0.0（API 12）；目标 SDK：HarmonyOS 26.0.0.105。编译工具：用户下载的 DevEco Studio 26.0.0.851 官方 Windows 包，已验证华为数字签名。应用包名保持 `cn.ketime.app`，显示名称“刻时”，使用原单字“刻”图标。

## 目录

- `entry/src/main/ets/pages/Index.ets`：ArkWeb、固定存储域、本地资源拦截、返回键。
- `entry/src/main/ets/services/NativePort.ets`：原生 HTTPS、AssetStore、密码学和回调监听。
- `entry/src/main/ets/services/WebBridge.ets`：受限页面接口、文件选择/保存、外部授权与触觉。
- `../harmony-runtime`：编译进入原生运行时的业务服务；不会作为网页脚本分发。
- `../tools/prepare-harmony.py`：从当前主 HTML、Android CSS/JS 和原 AI 规则生成应用资源。
- `build-harmony.ps1`：在当前用户和 SYSTEM 专用的纯英文临时目录构建；不创建目录链接，不复制凭据。
- `dist`：生成的 HAP、验证截图及校验信息。

## 构建与安装

执行 `powershell -File harmony/build-harmony.ps1` 可构建未签名调试 HAP。正式发行构建使用 `-Mode release`。编译成功不代表已签名，也不代表真机测试通过。

真机调试需要本人在华为官方开发工具授权页完成登录，手机开启开发者模式和 USB 调试并确认电脑授权。随后用 `-Sign` 生成针对本人账号和设备的签名构建；签名配置只写入私有临时构建工程，不写入公开源码。开发调试签名不能当作面向所有用户的商店发行签名。

应用在手机离线保存日程、项目、提醒、待收纳、成长曲线等数据。原 Android 数据请先导出 JSON，再在鸿蒙版恢复；不会自动读取安卓沙箱。账号密码、API Key、ChatGPT 授权不进入业务备份，跨平台需要本人重新连接。

## 安全边界

- 网页始终使用同一虚拟本地域 `http://127.0.0.1:8766/`，本地资源由应用拦截，无需启动网页 HTTP 服务。
- `/api` 在页面与原生之间传递，网页不能调用任意 URL、读取凭据、执行任意原生操作。
- HTTPS 地址、路径和方法固定白名单，禁止自动重定向和不安全证书降级。
- 敏感数据以不超过 1024 字节的分片保存在鸿蒙 AssetStore，最后原子切换索引；保存失败不主动覆盖旧记录，无明文回退。
- ChatGPT 保留 PKCE、state/nonce、单次回调、JWKS 验签、签发方/受众/有效期校验、刷新令牌及多账户设置。回调监听仅绑定本机回环地址，网页不获取令牌。
- 文件恢复沿用原版本的大小限制、格式校验、确认替换和保护快照；禁用模板中的系统自动备份扩展，以免自动备份敏感数据。

## 验证范围

2026-10-16：官方 SDK 编译 debug 和 release HAP 成功；17 组隔离服务测试通过，其中转换器和模型目录与现有 Python 实现对照，另覆盖打包原生 JS 启动、三提供方日程草稿、ChatGPT 签名验证/刷新/模型选择/退出、教学云验证码及 Cookie 隔离；打包界面通过隔离 Edge 浏览器回归（320/393/600 宽度、页面切换、备份恢复、本机模型测试桥接、缩放不影响其他页面）。所有测试使用合成样本，不使用真实账号、密码或付费 API。

同日已在官方 HarmonyOS 7.0.0.107（API 26）手机模拟器安装并启动调试 HAP，实际 ArkWeb 检查通过：普通/无头/无尾日程、待收纳、三个主页面、缩放与导航隔离；超过 1KB 的 UTF-8 虚构凭据通过真实 AssetStore 分片写入与重读，网页存储中无凭据明文；本机授权回调拒绝无效 state，三个 API 提供方状态接口正常。保存稳定后不卸载覆盖安装，业务数据及加密设置均保留。测试样本已清理，结果见 `dist/模拟器验证报告.json`、`dist/鸿蒙7模拟器功能验证.png`。

发现的限制：ArkWeb 的 localStorage 异步落盘，保存后立即强制终止进程时，最近的业务修改可能尚未持久化；等待 6 秒后的覆盖安装测试通过，加密设置在两种测试中均保留。此极端终止边界尚未解决，不能视为已具备正式发布级数据耐久性。

这些结果不能代替鸿蒙真机验证。HarmonyOS 5.0.5 模拟器在本机 AMD/Windows 虚拟化环境出现内核 IO-APIC timer panic，已停止旧实例，未修改 Windows 安全或虚拟化设置；所以最低版本 5 的运行兼容性仍未验证。原生文件保存器已能调起，但输入法首次启动要求额外隐私同意，已取消，文件读写端到端未标为通过。系统返回、触觉、真实课表、教学云及 AI 授权/付费请求仍需后续验收。没有真机签名包或商店发行签名。

## 本机模拟器入口

双击本目录 `start-emulator.cmd` 打开已经创建的官方 HarmonyOS 7 手机模拟器，首次冷启动需等待系统桌面；刻时已经安装，点击其图标即可。不是 Edge 模拟皮肤。此入口不下载镜像、不重新创建实例、不清空数据；只在本机使用，工具缓存被系统清理后需重新准备。

状态检查：`powershell -File harmony/emulator.ps1 -Action Status`；正常停止：`-Action Stop`。默认实例 `KetimePhone7`，端口 11111。工具路径从项目私有记录读取，不依赖全局 PATH。原生 Emulator 26 的有效 SDK 根目录必须是 `studio/sdk/default`，启动脚本仅对自身进程设置该值。调试包仅在 `appInfo.debug` 为真时允许本机 ArkWeb 调试，release 明确关闭；不要在调试包里输入正式密钥。
