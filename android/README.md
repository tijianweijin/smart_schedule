# 刻时 Android 1.0

当前维护版本：**1.0.15**。取消顶部产品名称及原导航栏，设置以文字入口放在日程表左侧。底部导航从左至右为“设置 / 日程表 / ＋ / 项目单 / 成长曲线”，仍铺满屏幕，操作区高度为 34px（系统底部安全区另计）。中央添加入口为导航栏自身的绿色色块，只显示“＋”，没有内嵌圆角框、边框或阴影，保留无障碍名称“添加日程”；可从四个页面直接添加日程。

日期栏采用“10月 5 周一”单行格式，日数字保持粗体，其他文字与之垂直居中。日历图标旁显示“2026年10月”，选择日期时同步更新，1～9月不补零，跨年周仍显示所选日期的年月；起始时间前显示浅色小字“每日起始自”。窄于 381px 的工具栏分为两行，避免文字和操作入口挤压。不再显示今天和前后周按钮，节假日入口统一放在设置中。待收纳的快速记录入口只显示“＋”，保留无障碍名称与原输入功能。

Android 设置为与日程表、项目单、成长曲线平级的独立滚动页面，不再显示居中悬浮窗或遮罩。选择设置时底部入口高亮，其他主页面隐藏；返回键回到进入设置前的页面，切换其他页面时清空未保存密码。节假日设置仍作为二级编辑弹窗，关闭后返回设置页。账号、模型/AI、备份及恢复功能保持不变，正式桌面版仍使用原设置弹窗。

待收纳为两列，作业截止时间简化为月日及时间；日程完成圆圈位于时间块底部；日程表扣除时间刻度栏后每屏等宽显示三天，左右滑动查看其余日期。打开日程表时默认将今天放在三天视窗中央，前后各一天；从其他页面返回时再次定位今天。周表两端增加相邻日期，周一和周日也可居中。手动滑动、勾选及选择历史日期不会被自动拉回。日历按钮去除边框、背景和阴影，保留图标、年月及键盘焦点提示；日历弹出面板样式不变。桌面正式网页仍为七天布局。

项目节点按每屏三列计算宽度，精简卡片留白、待办编辑按钮和标题层级。进入项目单时默认将首个未完成节点居中，完成后定位下一节点，节点本身顺序不变；首尾留有滚动边距以便居中。成长曲线按手机实际宽度绘制完整 SVG，日期最多四个刻度，保持文字尺寸并限制提示框在图内。Android 与 Edge 预览共用这些排版调整；正式桌面网页保持原有尺寸与导航。

新安装包沿用 `dist/刻时-Android-1.0.apk` 文件名和原签名，可以直接覆盖安装；请勿先卸载。重要数据建议升级前先导出备份。

打开日程表时，时间网格默认从设备当前本地时间往前两小时开始显示，精确到分钟，例如 09:46 时从 07:46 显示。早于设定起始时间则停在顶部；剩余时间不足一屏时停在底部，不扩展原有每日时间范围。日期栏与今日提醒仍固定显示。从其他页面返回、调整每日起始时间时重新定位；手动滚动后编辑或勾选日程不会抢占位置。此行为仅用于 Android 与 Edge 手机预览。

日历选择任意日期后，该日位于三天视窗中央。选择非今天的日期时，从设定的每日起始时间显示；选择今天时，按当前时间往前两小时显示，沿用上下边界限制。同一日期再次选择也会重新定位，手动滑动后的普通重绘不会抢占位置。

日历当前选中日期用深绿色底色及白字，今天未选中时用浅绿色底色；今天被选中时也使用深绿色。以日程视窗中央竖线落在哪一天为准，横向滑动、选择日期、重绘及尺寸变化后同步更新，不增加其他可见标志。

设置新增“智能模型选择 → 大模型选择”：GPT、DeepSeek、MiniMax、Kimi。GPT 保留原授权及模型选择；DeepSeek 支持密钥连接、实时模型目录、模型/强度自动保存、消息测试和日程助手。MiniMax/Kimi 明确为尚未接入。Android 密钥采用 Keystore 加密保存，不进入备份或安装包；电脑使用 DPAPI。Edge 预览只展示选项，密钥输入和联网调用仍禁用。真实 DeepSeek 连接需要用户在安装版或本机网页输入自己的 API Key，尚未验证真实账户。详见项目根目录的 `DeepSeek接入说明.md`。

## Edge 手机预览版

只有开始时间的日程称为“无尾日程”，只有结束时间的日程称为“无头日程”，不提供额外事件类型选择。添加日程、项目关联待办和 AI 草稿均可留空一端，至少保留一个时间；字段旁的“清空”按钮方便手机操作。无尾日程在线下显示名称及地点、向下半小时渐隐，完成圆圈跟在文字下方并随换行下移；无头日程在线上显示名称及地点、向上半小时渐隐，完成圆圈放在色块底部。普通日程圆圈同样在底部。渐隐带的局部重叠变红，并保持透明度渐隐；跨每日起始边界分段显示，但仍为同一日程。名称、完成与项目关联保持同步，重复日程支持仅修改本次的空时间。窄分栏内名称最多显示两行，完整信息保留在提示和编辑页。

完成圆圈保持右下角；无尾日程放在名称、地点下方靠右。紧贴每日起始时间的无头短片段使用下方可见操作区，避免被固定提醒栏挡住；无尾跨日续段也可直接勾选，两个片段仍同步同一日程。

同时提供 `dist/刻时-Android-Edge预览.html`。在 Windows 双击项目根目录 `preview-android-edge.cmd` 会使用 Edge 打开；也可以把 HTML 单文件发送到其他电脑，用 Edge 打开。不需要安装 Android 工具、启动 Python 服务或运行模拟器。

预览版复用主页面及 Android 专属样式和交互，支持三种屏幕尺寸、横竖屏、页面切换、返回、日程/项目编辑、成长曲线、待收纳、节假日及 JSON 备份/恢复。桌面鼠标也使用手机触控尺寸。顶部“加载示例”只替换预览数据，替换前会提示；不影响正式网页或手机。

这是**离线界面/本地功能预览，不是真正的 Android 系统**。学校登录、课表/作业同步、ChatGPT 联网以及 Keystore 等手机系统能力不可在此验收；账号输入与联网按钮停用，不读取电脑凭据，也不发送联网请求。预览数据以独立键 `ketime-android-edge-preview-v1` 保存，不读取旧版正式日程。数据备份格式与手机一致，可手动导入，但没有自动同步。

修改界面后，在项目根目录执行 `node tools/build-android-preview.js` 并刷新预览页。Android 构建脚本也会在 Node.js 可用时同时生成预览版，两个版本继续共用界面源文件。Edge 的浏览数据清理或换文件位置可能影响本地预览存储，请先导出备份。

Android 应用使用原网页版完整界面与业务逻辑，内嵌 Python 服务。**手机不需要电脑提供服务，不需要安装 Python。** 最低 Android 8.0；支持 arm64 手机和 x86_64 模拟器。

## 功能与迁移

- 日程表：一般/项目关联日程、重复及期限、按次完成、跨午夜、时间重叠红色提示、今日提醒、数字占位符。
- 项目单：项目/节点/待办编辑、关联同步、阻塞、节点独立完成及未完成待办提示、项目进度条。
- 成长曲线：日期筛选、项目代表色、完成度提示、缺失日期补记和完成停更规则。
- 待收纳：快速记录、勾选、编辑、删除、转日程/归项目，教学云作业导入。
- 北邮课表、教学云作业、节假日及调休设置；所有 API 保留原认证与防重复规则。
- ChatGPT：系统浏览器 OAuth、账户切换、模型/强度自动保存、更新模型、测试消息、日程助手、多日程排序和缺失信息草稿。
- Android 适配：横向滑动完整周表/节点、节点长按打开原右键菜单、系统返回关闭弹窗、系统文件选择/保存。

电脑数据不会自动同步到手机。在电脑设置中导出 JSON，然后在手机“设置 → 本地数据备份/恢复”导入。**账号密码和 ChatGPT 授权不随备份迁移，手机需重新填写/授权。** 两端仍然分别保存，恢复会替换手机当前数据。

## 安全与生命周期

- 学校凭据与 OAuth 令牌使用 Android Keystore AES-256-GCM 加密，存入应用私有目录，自动系统备份关闭。未使用 Windows DPAPI，也未打包开发电脑的 `.local` 数据。
- 仅绑定手机 `127.0.0.1:8766`；继承 Origin/Host/CSRF 校验、静态文件白名单、授权 state/nonce/PKCE、JWT 验证与令牌刷新。
- WebView 只允许刻时本机页面；其他 HTTPS 链接使用系统浏览器。禁止文件 URL、混合内容与第三方 Cookie；原生接口仅有备份导出及官方授权启动，不提供读凭据功能。
- 本地日程存于该应用 WebView 私有存储。升级同签名 APK 保留数据；卸载/清除应用数据会删除本机记录与凭据，先导出备份。
- 无后台常驻通知或精确闹钟（网页版原本没有）；成长日终沿用“下一次打开补记”，不能承诺关机/杀进程后仍执行任务。授权过程中若 Android 杀死应用进程，需返回应用重新发起登录。
- 云平台/教务真实网络同步需要手机能访问相应学校服务器；ChatGPT 需要账户权限及可访问 OpenAI 的网络。未将个人学校账号写入代码。

## 构建

需要 JDK 21、Gradle 8.11.1、Android SDK 35、Python 3.13。采用 Android Gradle Plugin 8.9.2 与 Chaquopy 17.0.0。

在项目根目录运行：

```powershell
# 仅在你已同意 Google Android SDK 官方许可时使用该参数。
.\android\tools\bootstrap.ps1 -AcceptSdkLicense
$env:KETIME_BUILD_PYTHON='C:\path\to\python.exe'
.\android\tools\build.ps1
# 生成独立签名、关闭调试的安装包：
.\android\tools\build.ps1 -Release
# 连接已开启 USB 调试的手机，安装 APK：
.\android\tools\build.ps1 -Install
# 运行连接设备上的 Android 原生测试：
.\android\tools\build.ps1 -Test
```

输出：`android/dist/刻时-Android-1.0.apk`（Release、项目独立签名、关闭调试），以及默认构建的 `刻时-Android-1.0-debug.apk`（开发调试包）。两个签名不同，不可互相覆盖安装。Release 的持久签名保存在 `.local/android-signing/ketime-release.p12`，签名密码由当前 Windows 用户级 DPAPI 加密保存在同目录。务必私下备份密钥及密码记录，后续版本复用此签名；不要提交到 Git。商店公开发布前还需核对隐私政策、授权许可与学校平台使用规则。

`syncKetimeWeb`/`syncKetimePython` 构建任务只收集明确列出的页面与服务源码，不递归收集项目。网页版改动通过 `node tools/embed-ui.js` 同步入口，再构建 Android 即可共用更新。

## 验证范围

宿主机可运行：`python -B -m unittest discover -s tests`、`node tests/android-browser.js`。Android 原生测试位于 `app/src/androidTest`，检查服务启动、配置、Keystore 加解密/篡改拒绝与凭据文件不可下载。真实手机上的系统授权返回、学校网络登录、软键盘和文件选择仍需设备验收，不能由桌面浏览器测试替代。
